Skrivanje podatkov

Steganografija, CSS triki in HTML komentarji — kako lahko skijemo podatke pred nepridipravi ali kako nepridipravi vgradijo zlonamreno programsko opramo pred našim nosom.

Varnost & Kriptografija
// SLIKA — hero

V sodobnem digitalnem svetu je zaščita podatkov postala ena izmed najpomembnejših nalog pri razvoju spletnih strani in spletnih aplikacij. Uporabniki vsakodnevno delijo osebne informacije, kot so elektronski naslovi, gesla, telefonske številke in bančni podatki, zato je pomembno, da so ti podatki ustrezno zaščiteni. Poleg klasičnih varnostnih metod se pogosto uporablja tudi tehnika skrivanja podatkov, imenovana steganografija.

Kaj sploh je skrivanje podatkov?

Skrivanje podatkov pomeni, da določene informacije niso neposredno vidne uporabniku ali napadalcu. Namen takšnega pristopa je zmanjšati možnost zlorabe občutljivih podatkov in otežiti dostop do njih.

// Razlikujemo med:

Skrivanjem podatkov — kjer podatki niso vidni; šifriranjem podatkov — kjer so pretvorjeni v neberljivo obliko; ter dejansko varnostjo sistema, ki vključuje zaščito strežnika, preverjanje uporabnikov in nadzor dostopa.

Raziskava Steganography using HTML Web Pages as a Carrier: A Survey poudarja, da je zaradi hitrega razvoja interneta zaščita osebnih podatkov postala nujna potreba sodobne družbe.

Steganografija in spletne strani

Steganografija je metoda skrivanja skrivnih informacij znotraj druge datoteke ali medija. Beseda izhaja iz grščine in pomeni »skrito pisanje«. Podatki se lahko skrivajo v slikah, videoposnetkih, zvoku, besedilu ali celo v HTML kodi spletnih strani.

// SLIKA — steganografija diagram

Pri spletnih straneh govorimo o HTML steganografiji, kjer HTML dokument služi kot nosilec skritih informacij. Prednost takšnega pristopa je, da spletne strani na internetu niso sumljive, saj jih uporabljamo vsak dan.

Metode skrivanja podatkov v HTML dokumentih

1. Skrivanje z uporabo presledkov

Ena izmed metod vključuje dodajanje ali odstranjevanje presledkov v HTML oznakah. Ker brskalnik dodatnih presledkov običajno ne prikaže, videz strani ostane enak, podatki pa so skriti v sami kodi.

<p>Besedilo</p> <p >Besedilo</p>

Na videz med njima ni razlike, vendar ena različica predstavlja binarno vrednost 1, druga pa 0.

2. Spreminjanje vrstnega reda HTML oznak

Podatke je mogoče skriti s spreminjanjem vrstnega reda HTML elementov, ne da bi se spremenil prikaz strani.

<u><i>Besedilo</i></u> <i><u>Besedilo</u></i>

3. Spreminjanje velikosti črk v oznakah

HTML oznake niso občutljive na velike in male črke, zato se podatki skrivajo z različnimi kombinacijami.

<UL> <ul>

Takšna metoda sicer deluje, vendar je lahko opazna izkušenim razvijalcem.

// SLIKA — prikaz HTML kode / devtools

4. Skrivanje podatkov v komentarjih

HTML omogoča komentarje, ki jih brskalnik ne prikaže. Ti se pogosto uporabljajo za razvojne opombe, a prav tako za skrivanje informacij.

<!-- Skrito sporočilo -->

5. Skrivanje v atributih HTML elementov

Podatki se skrivajo tudi v atributih, kot je id. Besedilo se pretvori v ASCII zapis in shrani kot del atributa.

<div id="A65B66"></div>

Uporaba JavaScript in CSS

Poleg steganografije razvijalci pogosto uporabljajo CSS in JavaScript za skrivanje elementov vmesnika.

/* CSS skrivanje */ display: none; visibility: hidden; /* JavaScript skrivanje */ document.getElementById("sporocilo").style.display = "none";
// Varnostno opozorilo

Takšni elementi niso varni — uporabnik jih odkrije z razvijalskimi orodji v brskalniku (DevTools). Ne shranjujte občutljivih podatkov na strani odjemalca.

Omejitve skrivanja podatkov

Čeprav steganografija omogoča prikrito komunikacijo, ima določene omejitve:

  • HTML dokumenti imajo omejen prostor za skrivanje večjih količin podatkov.
  • Dodajanje dodatnih oznak ali presledkov poveča velikost dokumenta in postane sumljivo.
  • Nekateri urejevalniki kode samodejno odstranijo presledke in s tem poškodujejo skrite podatke.
  • Preveč predvidljiv način skrivanja napadalci hitro odkrijejo.
// SLIKA — varnostni diagram / grafi

Kako napadalci izrabljajo steganografijo

Čeprav se steganografija pogosto uporablja za zaščito in prikrivanje podatkov, jo vse pogosteje izrabljajo tudi napadalci. Zaradi možnosti skrivanja informacij znotraj običajnih datotek predstavlja učinkovito metodo za prikrivanje zlonamerne dejavnosti in oteževanje zaznave napadov. Najpogosteje se uporabljajo slike, saj vsebujejo veliko količino podatkov, pri katerih majhne spremembe niso opazne človeškemu očesu. Ena izmed najbolj znanih metod je tehnika »Least Significant Bit« (LSB), pri kateri se skrivni podatki shranijo v najmanj pomembne bite slikovnih pik. Takšne spremembe običajno ne vplivajo na videz slike, zato uporabnik ne opazi razlike.

V praksi se ste steganografija v kibernetskih napadih uporablja za:

  • skrivanje zlonamerne programske opreme,
  • prikrito komunikacijo med napadalcem in okuženim sistemom,
  • krajo podatkov brez zaznave,
  • širjenje izsiljevalske programske opreme,
  • prikrivanje ukazov znotraj spletnih strani ali datotek

Eden izmed znanih primerov je bil odkrit leta 2020, ko so napadalci v spletnih trgovinah skrili zlonamerno kodo znotraj SVG slik na straneh za plačilo. Uporabniki niso opazili nič sumljivega, saj so bile slike videti kot običajni logotipi podjetij. Zlonamerna koda je bila skrita na način, ki ni povzročal sprememb v videzu strani, zato je niso zaznali niti nekateri varnostni sistemi.

Steganografija se uporablja tudi pri tako imenovanem »malvertisingu«, kjer je zlonamerna koda skrita v spletnih oglasih. Ob odprtju oglasa se lahko v ozadju prenese škodljiva programska oprema ali pa je uporabnik preusmerjen na okuženo spletno stran.

Povezava med steganografijo in kriptografijo

Veliko sodobnih sistemov združuje steganografijo in kriptografijo. Najprej se sporočilo šifrira, nato pa skrije v HTML dokument. Takšna kombinacija bistveno poveča varnost podatkov, saj napadalec težje odkrije in razbere skrito vsebino.

Zaključek

Skrivanje podatkov na spletnih straneh predstavlja pomemben del sodobne spletne varnosti. Tehnike, kot so HTML steganografija, skrivanje komentarjev, uporaba CSS in JavaScript ter šifriranje podatkov, omogočajo dodatno zaščito občutljivih informacij. Kljub temu skrivanje samo po sebi ne pomeni popolne varnosti — za učinkovito zaščito je nujno kombinirati varne strežniške sisteme, preverjanje uporabnikov in šifrirano komunikacijo. Žal pa tudi steganografija ni namenjena zgolj zaščiti informacij, temveč lahko predstavlja tudi resno varnostno tveganje. Zaradi tega sodobni varnostni sistemi vedno pogosteje vključujejo napredne metode za zaznavanje skritih podatkov in nenavadnih sprememb v datotekah ter omrežnem prometu.
